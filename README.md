# Lista de tarefas em React

App de lista de tarefas para adicionar, concluir e apagar tarefas, além de abrir uma página com os detalhes de cada uma.

## Tecnologias

- React 18 com Vite
- React Router para a página de detalhes
- Tailwind CSS para o visual
- Ícones do `lucide-react`

## Como rodar

```bash
npm install
npm run dev
```

Depois, abra o endereço que aparecer no terminal (normalmente `http://localhost:5173`).

## O que pratiquei

- Componentes, props e estado com `useState`
- Passagem de dados entre páginas pela URL
- Estilização com Tailwind
